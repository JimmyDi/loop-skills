# Loop Skills

Independently installable Agent Skills for [Loop](https://github.com/JimmyDi/loop).

## Catalog

Published skills belong in [skills/](skills/). The catalog currently has no entries.

## Install a skill

In Loop Web, open **Settings → Integrations → Skills** and add the GitHub folder URL of a published skill. For a local installation, select the folder containing its SKILL.md. Review the files, choose project or personal scope, then select the skill in chat.

## Add a skill

Copy the [authoring template](template/SKILL.md.template) to `skills/<name>/SKILL.md`. Bundle references, scripts, and assets as needed. Declare runtime dependencies inside the skill that uses them. See the [contribution guide](CONTRIBUTING.md) and [Loop compatibility notes](docs/loop-compatibility.md).
